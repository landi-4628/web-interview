## 怎么用这份资料

1. **先背要点**：每章开头的「八股要点」是面试直答版。
2. **再看案例**：每章末尾或小节里的「案例讲解」用代码帮你理解「为什么」。
3. **自己敲一遍**：把案例在浏览器控制台或 CodeSandbox 跑一遍，比只看文字快很多。
4. **对照场景题**：第 12 章把前面知识串成真实项目问题。
