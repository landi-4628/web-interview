## 1. HTTP 版本对比（一句话）

- **1.0**：一次请求一次 TCP  
- **1.1**：Keep-Alive 长连接、缓存头完善  
- **2.0**：多路复用，一个连接并行多个请求  
- **3.0**：QUIC/UDP，弱网更快

---

## 2. 常用状态码（场景记忆）

| 码 | 场景 |
| --- | --- |
| 200 | 正常返回 JSON |
| 301/302 | 短链跳转、未登录跳登录页 |
| 304 | 静态资源未变，用本地缓存 |
| 400 | 参数校验失败 |
| 401 | 未登录 / token 过期 |
| 403 | 有登录但无权限 |
| 404 | 路径或资源不存在 |
| 500 | 服务端代码崩了 |

```javascript
// axios 拦截器统一处理
axios.interceptors.response.use(
  (res) => res,
  (err) => {
    if (err.response?.status === 401) {
      router.push('/login');
    }
    return Promise.reject(err);
  }
);
```

## 3. GET vs POST

- **GET**：参数在 URL，可被缓存、收藏，不适合敏感大数据  
- **POST**：体里带 JSON，常用于提交表单、创建资源  

---

## 4. HTTPS 简化流程

1. 客户端：支持的加密套件  
2. 服务端：证书（公钥）  
3. 客户端验证证书是否可信  
4. 双方协商出**会话密钥**（对称加密，速度快）  
5. 之后数据用会话密钥加密传输  

**面试答法**：HTTPS = HTTP + TLS，防窃听、防篡改（证书链保证身份）。
