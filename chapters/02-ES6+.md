## 3. Set / Map

```javascript
// Set：去重
const ids = [1, 2, 2, 3];
const unique = [...new Set(ids)]; // [1, 2, 3]

// Map：键可以是对象（普通对象键会被转成 '[object Object]'）
const cache = new Map();
const key = { id: 1 };
cache.set(key, { data: 'xxx' });
cache.get(key); // { data: 'xxx' }
```

## 4. class 与继承

```javascript
class Animal {
  static kingdom = '动物';
  constructor(name) { this.name = name; }
  speak() { return `${this.name}~`; }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name); // 必须先调 super
    this.breed = breed;
  }
  speak() { return super.speak() + ' 汪汪'; }
}

new Dog('旺财', '柴犬').speak();
```

## 5. 模块化

```javascript
// utils.js
export const PI = 3.14;
export default function add(a, b) { return a + b; }

// main.js
import add, { PI } from './utils.js';
```

---

## 6. 可选链 & 空值合并

```javascript
const city = user?.address?.city;           // 避免 Cannot read property of undefined
const title = input ?? '默认标题';           // 只有 null/undefined 才用默认值
// 注意：?? 和 || 不同：0、'' 在 ?? 下会保留，在 || 下会被当成假值替换掉
const count = response.count ?? 0;
```

---

## 7. flat / flatMap

```javascript
[1, [2, [3]]].flat(2);           // [1, 2, 3]
[1, 2, 3].flatMap((n) => [n, n * 2]); // [1,2, 2,4, 3,6] —— map + 压平一层
```
