## 1. XSS：把恶意脚本插进页面

**存储型**：评论区存了 `<script>偷cookie</script>`，别人打开就中招。  
**反射型**：URL 里 `?q=<script>...`，页面未转义直接 `innerHTML`。  
**DOM 型**：前端用 `location.hash` 拼进 `eval` 或 `innerHTML`。

```javascript
// ❌ 危险
div.innerHTML = userInput;

// ✅ 安全
div.textContent = userInput;
// 或 Vue/React 默认转义文本；富文本用 DOMPurify 白名单过滤
```

**防御**：输出转义、CSP 头 `Content-Security-Policy: script-src 'self'`、Cookie 设 `HttpOnly`。

---

## 2. CSRF：借你的登录态发请求

攻击站点里藏表单，自动 POST 到你的银行转账接口（浏览器会自动带 Cookie）。

**防御**：

- 敏感操作用 **Token**（Header 里带，攻击者读不到）  
- `SameSite=Strict/Lax` 的 Cookie  
- 校验 `Referer/Origin`

```javascript
//  axios 统一带 CSRF token（后端下发）
axios.defaults.headers.common['X-CSRF-Token'] = getCsrfFromCookie();
```
