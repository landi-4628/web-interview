## Webpack 五大概念（记一张图）

```
入口 entry → 模块依赖图 → loader 转译 → plugin 增强 → 出口 output
```

**案例：引入 `.vue` 和 `.scss`**

```javascript
module.exports = {
  entry: './src/main.js',
  module: {
    rules: [
      { test: /\.vue$/, loader: 'vue-loader' },
      { test: /\.scss$/, use: ['style-loader', 'css-loader', 'sass-loader'] },
    ],
  },
  plugins: [
    new HtmlWebpackPlugin({ template: 'index.html' }),
  ],
};
```

## Vite 为什么开发时快？

| | Webpack dev | Vite dev |
| --- | --- | --- |
| 启动 | 先打包整包再开服务 | 直接起服务，按需编译 |
| 热更新 | 往往重新走依赖链 | ESM + 精确 HMR |

```javascript
// 你改了一个组件，Vite 只重新请求这一条模块
// Webpack 可能要从入口重新算一大块 chunk
```

**生产环境**：Vite 用 Rollup 打包，和 Webpack 一样要做 tree-shaking、代码分割。

---

## 打包优化（面试答法 + 案例）

1. **路由懒加载**：`() => import('./views/Home.vue')`  
2. **splitChunks**：把 `vue`、`element-plus` 拆成 vendor  
3. **CDN + externals**：大库不打进 bundle  
4. **gzip / brotli**：Nginx 开启压缩  
5. **长效缓存**：文件名带 contenthash，`app.[hash].js`
