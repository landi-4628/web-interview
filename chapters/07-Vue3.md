## 1. Proxy 对比 defineProperty

```javascript
const state = reactive({ user: { name: 'a' }, list: [1, 2] });

state.user.age = 18;   // ✅ 新增属性可监听
state.list[0] = 99;    // ✅ 下标修改可监听
state.list.length = 0; // ✅ length 也可
```

## 2. Composition API 实战

```vue
<script setup>
import { ref, computed, onMounted } from 'vue';

const keyword = ref('');
const list = ref([]);

const filtered = computed(() =>
  list.value.filter((i) => i.name.includes(keyword.value))
);

async function load() {
  list.value = await fetch('/api/list').then((r) => r.json());
}

onMounted(load);
</script>
```

**好处**：同一业务的 `ref + 方法 + 生命周期` 写在一起，大组件比 Options API 好维护；可抽成 `useXxx()` 复用。

## 3. ref vs reactive

```javascript
const count = ref(0);
count.value++; // 模板里自动解包，脚本里要 .value

const form = reactive({ name: '', age: 0 });
form.name = 'Tom'; // 不用 .value

// 解构 reactive 会丢响应式 → 用 toRefs(form)
const { name } = toRefs(form);
```
