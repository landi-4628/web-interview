## 1. el-table 几千条数据卡顿？

**原因**：DOM 节点过多，滚动/重排成本高。

**方案**：

1. **分页**：后端分页，每页 20～50（业务最常见）  
2. **虚拟滚动**：只渲染可视行（`el-table-v2` 或第三方 virtual-scroll）  
3. **减少列复杂度**：少嵌套组件、少自定义 render  
4. **固定列宽**：避免频繁自动算列宽触发回流  

---

## 2. 首屏白屏时间过长怎么排查？

**步骤**：

1. Lighthouse / Performance：看 FCP、LCP、TBT  
2. Network：是否 JS bundle 过大、是否串行请求接口瀑布  
3. 是否阻塞渲染的同步 script、是否未做路由懒加载  
4. 图片是否过大、是否缺骨架屏导致「看起来白」  

**优化**：拆包、CDN、预加载关键资源、接口合并、SSR/SSG（若 SEO 需要）。

---

## 3. 打包体积过大如何瘦身？

- `rollup-plugin-visualizer` / `webpack-bundle-analyzer` 找大头  
- 按需引入 UI 库、替换重量级依赖  
- `manualChunks` 拆 vendor  
- 生产环境 source map 关掉或外置  
- 开启 gzip/brotli

## 4. 移动端适配怎么做？

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

```css
/* rem：根字体 = 屏幕宽度 / 10 */
html { font-size: calc(100vw / 10); }
.card { width: 7rem; }

/* 或 vw：设计稿 750px，1px = 100vw/750 */
width: calc(200 * 100vw / 750);
```

Flex + 安全区 `env(safe-area-inset-bottom)` 处理刘海屏。

## 5. 怎么解决跨域？

开发：**devServer proxy**；生产：**后端 CORS** 或 **Nginx 同域反代**。详见 [03-浏览器原理.md](./03-浏览器原理.md)。

## 6. 刷新后 Vuex/Pinia 数据丢失？

```javascript
// pinia 持久化插件或自己写
const store = useUserStore();
watch(
  () => store.$state,
  (state) => sessionStorage.setItem('pinia-user', JSON.stringify(state)),
  { deep: true }
);
// 启动时 hydrate
```

敏感 token 优先 **HttpOnly Cookie**，不要只放 localStorage。

## 7. 怎么防止按钮重复点击？

```javascript
const loading = ref(false);
async function submit() {
  if (loading.value) return;
  loading.value = true;
  try {
    await api.submit(form);
  } finally {
    loading.value = false;
  }
}
// 或对接口层 throttle / 提交后 disable 按钮 2s
```

## 8. 图片加载失败如何处理？

```vue
<img :src="url" @error="onImgError" />

<script setup>
function onImgError(e) {
  e.target.src = '/assets/placeholder.png';
  e.target.onerror = null; // 防止占位图也失败死循环
}
</script>
```

CDN 侧可做多级降级、webp 失败回退 jpg。
